# MacAgent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a menu-bar-resident, Liquid Glass, offline Mac agent: Swift host (UI, tiers, memory) + TypeScript MCP tool server (typed, path-policed macOS tools).

**Architecture:** Swift app owns UI/hotkey/App Intents, SQLite tier-0 memory, Foundation Models tier-1 routing, LM Studio tier-2 agent loop, and an MCP stdio client. `mac-tools` (Node/TS) exposes allowlisted tools with MCP annotations; host decides confirmation from annotations; server independently enforces path policy and audits.

**Tech Stack:** Swift 6.3 / SwiftUI / AppKit / FoundationModels / AppIntents / SQLite3 C API / Carbon hotkey; XcodeGen; Node 25 + TypeScript + `@modelcontextprotocol/sdk` + zod; `node --test`; LM Studio (MLX) `qwen3-8b`.

**Spec:** `docs/superpowers/specs/2026-09-27-mac-agent-design.md`

## Global Constraints
- Deployment target macOS 26.0; Swift 6 language mode; no third-party Swift packages.
- mac-tools: only `@modelcontextprotocol/sdk`, `zod`, `typescript`, `@types/node`. `execFile` with argv arrays only; no `exec`, no `shell: true`.
- Allowed roots: `~/Projects ~/Work ~/Downloads ~/Documents ~/Desktop`. Denied roots per spec.
- Caps: 20 results, 20 KB read, 50 file ops/request. Trash only, never unlink.
- No timers/polling in host at idle; MCP child idle-exit 300 s; LM Studio request `ttl: 300`.
- Names: app `MacAgent`, bundle `com.harshvaid.MacAgent`, URL scheme `macagent`, MCP server name `mac-tools`.

## Review Focus
1. Path arg `~/Downloads/../.ssh/id_ed25519` → rejected (normalize before prefix check). Test in Task 2.
2. Symlink inside allowed root pointing to `~/Library` → rejected (realpath before prefix). Test in Task 2.
3. Query with only punctuation/whitespace (`"  ??? "`) → tier 0 miss, tier 1 returns `.unknown`, UI shows "didn't understand", no tool runs. Test in Task 7.
4. Tier 2 unavailable (LM Studio down / model missing) → palette shows actionable message with `lms` command, no hang (5 s connect timeout). Test in Task 9.
5. Intent cache hit whose target path no longer exists → cache row invalidated, falls through to tier 1. Test in Task 6.
