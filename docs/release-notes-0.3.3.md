# Muon 0.3.3: Open With › Muon

- **Finder › right-click a file › Open With › Muon.** The palette opens with the file attached; type what you want done with it: *give me a brief*, *analyse it*, *what is the total*, *fix grammar*. Works for folders too, and from Terminal: `open -a Muon report.pdf`. Muon is never the default app for anything.

Everything in [0.3.2](https://github.com/harshdvaid24/muon/releases/tag/v0.3.2) applies: name a file to have it read, analyse/brief requests, the paperclip button, faster medium documents.
