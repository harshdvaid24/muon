Why it's fast

It only thinks as hard as it has to.

Most requests never touch a big model. The more you use Muon, the more it answers from memory.

Tier 0 · memory
~0 ms

Repeated requests replay from a tiny local cache. No model at all.

Tier 1 · on-device
~1 s

Apple's built-in model routes single steps and chat. No app memory used.

Tier 2 · local LLM
on demand

LM Studio plans multi-step work, only when your Mac can spare the memory, then unloads.

Private by design

Your files never leave your Mac.

Muon was built so a model can never do something you didn't approve.

No shell, everTyped tools only, running allowlisted programs with argument lists.

Allowed folders only~/Library, ~/.ssh, /System and other protected places are always refused.

You approve every changeMoves, renames, quits and builds ask first. Releases get a system dialog.

Delete means TrashNothing is ever permanently deleted. Put Back always works.

One door to the internetOnly the web-search tool goes online, and only when you ask.

Everything is loggedAn audit log of every action — paths only, never file contents.

Install

Up and running in a minute.

Needs macOS 26 on Apple Silicon with Apple Intelligence on, and Node.js 20+ (brew install node).

Download

The easiest way.

  1. Download Muon.zip and move Muon.app to Applications.
  2. Open it. If macOS blocks it, go to System Settings › Privacy & Security › Open Anyway.
  3. Press ⇧⌥Space.

Homebrew

For people who live in the terminal.

brew install --cask harshdvaid24/tap/muon

From source

Xcode 26 and Node 20+.

git clone https://github.com/harshdvaid24/muon.git
cd muon/mac-tools && npm install && npm run build
cd .. && scripts/build.sh && scripts/run.sh
