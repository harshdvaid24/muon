Why it's fast

It only thinks as hard as it has to.

Common requests (writing, documents, screenshots, cleanup, rules) are parsed directly, so they never depend on a model guessing. The rest goes to the smallest tier that can handle it.

1 · parse
Deterministic first

Writing, documents, screenshots, voice, receipts, cleanups, rules, file names, help: parsed directly, 0 ms, no model guessing.

2 · remember
Memory

Anything you asked before replays from a capped local cache in milliseconds.

3 · on-device
Apple's model

Guided generation straight into a typed command. About a second. No app memory.

4 · only if needed
Local LLM

Multi-step plans, images, very long text. Loads when the Mac can spare it, unloads after 5 min.

5 · act
Typed tools

56 tools, argv only, path policy, one confirmation card per change. Never a shell.

6 · learn
It gets smarter

Intent cache, aliases, rules, For you, recent requests. Capped, on-device.

Tier 0 · memory
~0 ms

Repeated requests replay from a small local cache. No model at all.

Tier 1 · on-device
~1 s

Apple's built-in model handles single steps, chat and all writing and explaining. No app memory used.

Tier 2 · local LLM
on demand

LM Studio (Qwen 3.5, MLX) plans multi-step work, reads images and very long text. Loads only when your Mac can spare it, then unloads.

Private by design

Your files never leave your Mac.

Your text, documents, screenshots and recordings are processed on the Mac. Muon was built so a model can never do something you did not approve.

No shell, everTyped tools only, running allowlisted programs with argument lists.

Allowed folders only~/Library, ~/.ssh, /System and other protected places are always refused.

You approve every changeMoves, renames, quits, builds, commits and saved files ask first. Releases get a system dialog.

Delete means TrashNothing is ever permanently deleted. Put Back always works.

The internet is a few named toolsOnly web search, page reading and open-in-browser go online, and only when you ask.

Everything is loggedAn audit log of every action. Paths only, never file contents.

Install

Up and running in a minute.

Needs macOS 26 on Apple Silicon with Apple Intelligence on, and Node.js 20+ (brew install node). Optional: LM Studio for multi-step planning and images, Laya for faster routing. Check your setup with Muon --diagnose.

Download

The easiest way.

  1. Download Muon.zip and move Muon.app to Applications.
  2. Open it. If macOS blocks it, go to System Settings › Privacy & Security › Open Anyway.
  3. Press ⇧⌥Space.

Homebrew

For people who live in the terminal.
